# Jamiu NovaPersona Portfolio

A new, standalone portfolio for **Jamiu Abdulfatai**. Recreates the NovaPersona reference's white/grey/lime direction, three-column introduction, portrait card, accordion services, work grid, case previews, skills, experience, contact layout and shared footer with Jamiu's own content.

## Run

Requires Node 20+ and Python 3. No package installation is needed.

```sh
npm run dev
```

Open `http://localhost:4173`. Run `npm run check` to check content and routing; `npm run build` creates `dist/` for static hosting. `npm run preview:export` generates `dist/preview.html`, a file-openable preview using the actual shared components. It uses hash navigation for local viewing; the deployed site uses normal page URLs.

## One design system

| Change | Single source |
| --- | --- |
| Colours, typography, spacing, radii, motion | `src/styles/tokens.css` |
| Shared card styling and named variants | `src/styles/site.css` |
| **Every card** | `Card()` in `src/components/ui.js` |
| Buttons, badges, headings, page intros, form fields, stats | `src/components/ui.js` |
| Navigation, footer, shared call to action | `src/components/layout.js` |
| Personal details, projects, skills and notes | `src/content.js` |
| Repeated portfolio sections | `src/sections.js` |
| Page compositions | `src/pages.js` |
| Accessible menu, tabs, filters and form | `src/app.js` |

Card variants preserve layout differences without duplicating the base card. Changing a token or shared primitive updates every consumer on every page. The style-guide page demonstrates the same real components used by the portfolio.

## Pages

Home, About, Services, Case Study, Design Notes, Contact, Style Guide, six project pages and three design notes. Direct URLs are generated by the build. The mobile menu, service accordion, keyboard-operable tabs and category filters use no third-party libraries. Reduced-motion preferences are respected.

## Content and assets

Content and project artifacts come from Jamiu's existing `HandlerJnr/Abdulfatai-Portfolio` repository. Images and CV currently use its public raw GitHub URLs, allowing preview without copying or depending on the paused Vercel site. These URLs require connectivity and remain coupled to the original repository; self-host the assets in `public/assets/` for complete independence. The portrait is Jamiu's existing illustrated portrait.

The template's fictional customers, awards, ratings and conversion claims are replaced by personal background and documented project scope. The design notes are new reflections based on existing project accounts. Settle remains labelled research in progress. No anonymous testimonials or invented claims are included.

The contact form opens a **mailto draft**; it does not send messages or claim server-side delivery. A connected email app is needed. Direct contact links remain available.

## Deploy

Any static host can publish `dist/`. For Vercel: framework **Other**, build `npm run build`, output directory **dist**. No rewrites are required because each route has its own HTML file.

## Reference and scope

Reference: `https://novapersona.webflow.io/`, including its About and Contact layouts. The supplied `.h2d` file could not be materialized in this environment, so the live site was used. This is an independently implemented adaptation, not the original licensed Webflow template or a claim of pixel-for-pixel equivalence. Shared component architecture and Jamiu's real content intentionally replace the template's placeholders.

## Extended portfolio

The Explore navigation includes Certifications & recognition, Brand & identity, Logos & marks, Design systems and AI practice. Original documents, issuer verification links and artwork live in `collections` in `src/content.js`. Brand cards include expandable page galleries. These collections all render through the shared `Card` primitive and `CollectionPage` renderer. Seven additional original case studies are in `extendedProjects`; Academic Proofreader has an overview page. The `/certificates/` route aliases `/credentials/`.

The AI practice page describes the work and tools. The original portfolio's backend agent is not connected in this static preview.
